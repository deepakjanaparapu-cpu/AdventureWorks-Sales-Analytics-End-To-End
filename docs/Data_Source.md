# Data Source Documentation

## Dataset

Microsoft AdventureWorks Dataset

## Description

AdventureWorks is a sample business dataset provided by Microsoft and widely used for Business Intelligence, Power BI, SQL Server, and Data Analytics training.

## Available Tables

### Fact Tables

- Sales Data 2020
- Sales Data 2021
- Sales Data 2022
- Returns Data

### Dimension Tables

- Customer Lookup
- Product Lookup
- Product Categories Lookup
- Product Subcategories Lookup
- Territory Lookup
- Calendar Lookup
